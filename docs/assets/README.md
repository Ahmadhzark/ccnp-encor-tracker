# Product assets

Drop your marketing/brand images here. The README and marketplace listing
reference these paths — add real files to replace the placeholders.

| File | Purpose | Recommended size |
|---|---|---|
| `logo.png` | Product logo | 480×480 (transparent) |
| `banner.png` | README / listing banner | 1600×600 |
| `og-image.png` | Social share image (referenced in `index.html`) | 1200×630 |
| `thumbnail.png` | Marketplace thumbnail | 1200×800 |
| `screenshot-dashboard.png` | Dashboard capture | ≥1440 wide |
| `screenshot-labs.png` | Labs capture | ≥1440 wide |
| `screenshot-analytics.png` | Analytics capture | ≥1440 wide |
| `mockup-laptop.png` | Laptop device mockup | — |
| `mockup-phone.png` | Phone device mockup | — |
| `mockup-tablet.png` | Tablet device mockup | — |

**Tips**
- Capture real screenshots at a wide viewport in each theme (Copper/Midnight look great for light/dark contrast).
- For device mockups, free tools: Shots.so, MockuPhone, Screely.
- Put the 1200×630 `og-image.png` in **`public/`** too (so it's served at the site root for social scrapers) and update the URLs in `index.html`.
