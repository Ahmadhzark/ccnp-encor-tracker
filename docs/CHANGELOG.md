# Changelog

All notable changes to this product are documented here. This project follows
[Semantic Versioning](https://semver.org) (`MAJOR.MINOR.PATCH`) and the
[Keep a Changelog](https://keepachangelog.com) format.

## [1.0.0] — Initial release

### Added
- Command‑centre **Dashboard**: weighted progress ring, exam countdown, today's plan, study‑session timer, pace card, review card, streaks, quick actions.
- **Topics** with exam‑angle blurbs, confidence, notes, bookmarks, tags, search/filter/sort.
- **150 detailed labs** across all six exam domains, with status, time logging, reflections and attachments.
- **Flashcards**, topic‑linked **Notes**, **Log** with heatmap, **Analytics**, and **Goals/achievements**.
- **4 full themes** (Copper, Midnight, Ocean, Meadow).
- **Backup / restore** to JSON and progress reset.
- **PWA**: installable, offline‑first, auto‑updating.
- **About** page with brand and links.

### Engineering
- TypeScript **strict** mode across the codebase.
- Top‑level **ErrorBoundary** for graceful failure recovery.
- SEO: descriptive meta, Open Graph / Twitter tags, `robots.txt`, `sitemap.xml`.
- Full documentation suite in `docs/`.
- CI workflow to build and deploy to GitHub Pages.
