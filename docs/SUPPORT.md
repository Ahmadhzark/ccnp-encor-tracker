# Support

Thanks for using the Certflow CCNP ENCOR Tracker.

## Getting help

1. **Check the docs first** — most questions are answered in [FAQ.md](FAQ.md), [INSTALLATION.md](INSTALLATION.md) and [DEPLOYMENT.md](DEPLOYMENT.md).
2. **Search issues** — your question may already be answered on the repository's Issues tab.
3. **Contact** — reach Certflow:
   - Email: **usecertflow@gmail.com**
   - GitHub: **@certflow-0**

When contacting support, include: what you tried, the exact error text, your OS/browser and Node version (`node -v`), and a screenshot if relevant. It gets you a faster answer.

## What's covered

- Setup, build and deployment questions.
- Bug reports for the product as shipped.
- Guidance on the documented customization points.

## What's out of scope

- Custom feature development and one‑on‑one code changes (available as paid work).
- Third‑party hosting/account issues (contact that provider's support).
- Modifications you've made that diverge from the shipped code.

## Updates

Bug‑fix and minor updates are provided per your [license](../LICENSE.md) tier. Watch the repository or check [CHANGELOG.md](CHANGELOG.md) for releases.
